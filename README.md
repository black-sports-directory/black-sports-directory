# Black Sports Directory UK

The website for Black Sports Directory UK. It is a single static page hosted on GitHub Pages.

- Listings come live from the "Website view" tab of the master Google Sheet (published to the web as CSV). Mark a row Live in the sheet and it shows on the site within a few minutes.
- Settings (sheet feed, form link, contact email) are in the `CONFIG` block near the bottom of `index.html`.
